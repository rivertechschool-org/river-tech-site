# Little beginnings

Illustrated characters and props created for River Tech's approved opening, version 24.1. The drawings depict fictional characters, not photographs of students. The River Tech logo is supplied by the school.

Cartwheel motion is adapted from Carnegie Mellon University Motion Capture Database, subject 90, trial 04, frames 340–640 at the original 120 Hz. The data used in this project was obtained from mocap.cs.cmu.edu. The database was created with funding from NSF EIA-0196217.

Source and reuse terms: http://mocap.cs.cmu.edu/faqs.php and http://mocap.cs.cmu.edu/search.php?subjectnumber=90 . BVH conversion by Bruce Hahne / cgspeed, from the MotionBuilder-compatible release mirrored at https://github.com/una-dinosauria/cmu-mocap . Only the added calibration frame was discarded before extracting the take; illustrated fingers are not captured finger motion.

`story.js` preserves the approved scene. `boy-unified-v24.js` draws one source character throughout; `boy-performance-v19.js` still imports its motion adapter through `boy-unified-v19.js`. Older module names in this folder are intentional dependencies.
